## Задача 2 

Сценарий выполения задачи:

- создайте свой репозиторий на докерхаб; 
- выберете любой образ, который содержит апачи веб-сервер;
- создайте свой форк образа;
- реализуйте функциональность: 
запуск веб-сервера в фоне с индекс-страницей, содержащей HTML-код ниже: 
```
<html>
<head>
Hey, Netology
</head>
<body>
<h1>I’m kinda DevOps now</h1>
</body>
</html>
```
Опубликуйте созданный форк в своем репозитории и предоставьте ответ в виде ссылки на докерхаб-репо.

**Процесс:**
* `docker image pull httpd`
* `docker create --name httpd httpd`
* `docker run --rm httpd cat /usr/local/apache2/conf/httpd.conf > my-httpd.conf` (чтобы поправить конфиг, но мне не понадобилось - просто узнал как делать)
* создать файл `index.html `
* для проверки дать команду `docker run -dit --name my-apache-app -p 8080:80 -v C:\Users\vah\docker\httpd:/usr/local/apache2/htdocs/ httpd`
* `docker stop my-apache-app`
* `docker build -t my-apache2 .`
* `docker run -dit --name my-running-app -p 8080:80 my-apache2`
* `docker tag my-apache2 avakhutinskiy/my-apache-vah`
* `docker push avakhutinskiy/my-apache-vah`
