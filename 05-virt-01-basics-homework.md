8. **Linux сервера:**
9. Запустить VMware vCenter Converter Standalone.
10. Нажать Convert machine. ![](https://avatars.mds.yandex.net/get-zen_doc/3300410/pub_5ed006db1095633ca6f4a8b3_5ed006df7906ff4e9c591a8f/scale_1200)
11. Выберем исходную систему в мастере преобразования машин. Выберите Powered on и Remote Linux machine. Укажем IP-адрес, имя пользователя и пароль, используемые на удаленном компьютере Linux. Также необходимо отредактировать файл /etc/sudoers и сделать так, чтобы пользователь мог запускать sudo без ввода пароля. ![](https://avatars.mds.yandex.net/get-zen_doc/3502204/pub_5ed006db1095633ca6f4a8b3_5ed006dfb002c5089c1bcaa7/scale_1200)
12. Т.к. хост ESXi, на котором требуется запустить преобразованную виртуальную машину, управляется vCenter, введем IP-адрес сервера vCenter и введем учетные данные администратора vCenter![](https://avatars.mds.yandex.net/get-zen_doc/3415797/pub_5ed006db1095633ca6f4a8b3_5ed006df24878c447907e878/scale_1200)
13. **Destination Virtual Machine**. Выберем датацентр для хранения виртуальной машины и введем имя целевой виртуальной машины, например Ubuntu18-04-vm. ![](https://avatars.mds.yandex.net/get-zen_doc/2404796/pub_5ed006db1095633ca6f4a8b3_5ed006df9217f57f7c9a7f55/scale_1200)
14. **Destination Location**. Выберем узел ESXi для запуска виртуальной машины и хранилища данных для файлов виртуальных машин. Можно также выбрать версию виртуальной машины. ![](https://avatars.mds.yandex.net/get-zen_doc/1704908/pub_5ed006db1095633ca6f4a8b3_5ed006e10e3bde48babeb4bc/scale_1200)
15. **Options**. На этом шаге можно изменить различные параметры преобразования. **Data to copy**. Можно выбрать только пользовательские или все диски для копирования и выбрать тип выделения ресурсов виртуального диска ("тонкое" или "толстое" выделение ресурсов). Кроме того, каждый виртуальный диск можно хранить в другом хранилище данных. Установим флажок "Создать оптимизированный макет раздела" (Create optimized partition layout). Этот параметр используется для оптимизации выравнивания разделов диска. **Devices**. Установим необходимый объем памяти для целевой виртуальной машины во вкладке Память (Memory). Установим контроллер диска, количество процессоров и ядра процессоров во вкладке Другое (Other). **Networks.** Выберем количество виртуальных сетевых адаптеров для подключения к виртуальной машине. Затем выберем виртуальную сеть, к которой должен быть подключен каждый сетевой адаптер, тип сетевого контроллера и снимем флажок Connect at power-on, т.к. после конвертации поработаем с машиной в тестовом режиме, изменив IP-адрес. 
16. **Advanced options**. Параметры постконверсии находятся в этом разделе. В нашем случае для преобразования физического сервера Linux в виртуальную машину VMware доступна только «Опция перенастройки целевой виртуальной машины» (Reconfigure destination virtual machine option). Этот параметр используется для настройки загрузчика, обновления драйверов, используемых операционной системой, для оптимизации работы виртуальной машины в виртуальной среде VMware (с соответствующим виртуальным оборудованием). 
17. **Helper VM network.** В процессе преобразования сервера Linux в виртуальную машину VMware vCenter Converter создает вспомогательную виртуальную машину на целевом хосте/хранилище данных. Вспомогательная виртуальная машина должна иметь доступ через сеть к исходной физической машине под управлением Linux, чтобы клонировать все файлы исходной машины. В этом разделе можно настроить IP-адрес, маску сети, шлюз и DNS-серверы, используемые для сетевого подключения вспомогательной виртуальной машины. ![](https://avatars.mds.yandex.net/get-zen_doc/3415797/pub_5ed006db1095633ca6f4a8b3_5ed006e10716447d3111d122/scale_1200)
18. Далее проверяем все настройки преобразования P2V Linux и, если все правильно, нажмите кнопку Готово (Finish), чтобы начать процесс преобразования. ![](https://avatars.mds.yandex.net/get-zen_doc/3431006/pub_5ed006db1095633ca6f4a8b3_5ed006e2169c1b3afe0d067a/scale_1200)
19. Продолжительность преобразования зависит от объема данных, хранящихся на дисках исходного компьютера Linux. Если после завершения преобразования в VMware vCenter Converter отображается состояние Завершено (Completed), можно запустить целевую виртуальную машину Linux в интерфейсе VMware vSphere Client.
